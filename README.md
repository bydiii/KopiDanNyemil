# Kopi dan Nyemil ☕
Aplikasi mobile pemesanan kopi dan makanan ringan berbasis Android.

## Fitur
- Splash / Welcome
- Sign up, Login, Register (simulasi lokal, tanpa database)
- Home dengan 10 menu dummy dan tombol tambah pesanan
- Page Crosscheck Orderan menu, bisa edit dan hapus
- Profile dan edit nama
- Alamat pengiriman
- Konfirmasi pesanan
- Navigasi sederhana antarhalaman

## Teknologi
- Kotlin
- Android Studio
- Jetpack Compose
- Material 3

## Cara menjalankan
1. Ekstrak project.
2. Buka folder `KopiDanNyemil` melalui Android Studio (`Open`).
3. Tunggu Gradle Sync selesai.
4. Pilih emulator atau perangkat Android.
5. Klik **Run**.

Data akun dan pesanan hanya simulasi selama aplikasi berjalan. Tidak menggunakan database.
